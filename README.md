# Actuary Recall

A phone-first progressive web app for learning actuarial mnemonics through active recall and spaced practice.

## Features

- Daily and weakest-first revision sessions
- Recall, reverse-recall, learn and exam-sprint modes
- Device-local mastery and review scheduling
- Searchable acronym library
- Offline support when installed on a phone

The learning content is generated from `source-acronyms.md` with `node generate-data.mjs`.
